# Komprehension

A Kotlin compiler plugin that brings Scala-style for-comprehensions to Kotlin.

> **Status: work in progress.** The DSL, the runtime and the build are in place; the IR transformation
> is not implemented yet, so `comprehend { ... }` currently throws at runtime. See
> [`docs/design.md`](docs/design.md) for the design and the implementation plan (written in Japanese).

## What it looks like

```kotlin
val result = comprehend {
    val (name, subjects) = from(scores)
    val eng = subjects["English"].bind()
    val math = from(subjects["Math"])

    where(eng >= 70)

    name to (eng + math)
}
```

The plugin rewrites the block into nested `flatMap` calls, so the code above is equivalent to a
hand-written chain but reads as a flat sequence of bindings.

- `from(source)` and `source.bind()` are the same generator operation — use whichever reads better.
- Supported sources: `Iterable`, `Sequence`, `Array`, `Map` (binds `Pair<K, V>`) and nullable values.
  A `null` source contributes no elements.
- `where(condition)` drops the current branch.
- The last expression of the block is the result, and `comprehend` always returns `List<R>`.

The DSL is declared as ordinary Kotlin, so type inference and code completion work without any IDE plugin.

## Building

```console
./gradlew build
```

If `:kotlinNpmInstall` fails over a `packageManager` mismatch, the cause is a `package.json` in a
directory above this repository; `gradle.properties` already opts out of yarn to avoid it.

## Tests

The [Kotlin compiler test framework][test-framework] is set up for this project. To add a test, drop a
`.kt` file into a [compiler-plugin/testData](compiler-plugin/testData) sub-directory: `testData/box` for
codegen tests that run the compiled code, `testData/diagnostics` for expected-error tests. Expectation
files are generated on the first (failing) run. The JUnit 5 test classes are regenerated by the
`generateTests` Gradle task, which also runs automatically before `compileTestKotlin`.

Installing the [Kotlin Compiler DevKit][test-plugin] IntelliJ plugin — already configured in this
repository — makes running individual tests easier.
